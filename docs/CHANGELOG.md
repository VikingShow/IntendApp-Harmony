## [1.0.0] - 2024-10-13

### 🎉 首次发布

EasyFlow 1.0.0 正式发布！这是第一个稳定版本，提供完整的关键路径法（CPM）项目管理功能。

### ✨ 新增功能

#### 核心功能
- **Canvas 可视化网络图**
  - 基于 Canvas 2D 的交互式项目网络图
  - 支持普通模式和缩略模式双模式渲染
  - 流畅的拖拽、缩放（0.3x-3x）、平移交互
  - 自动布局和手动调整支持

- **关键路径法（CPM）算法**
  - 完整实现 CPM 算法，O(V+E) 时间复杂度
  - 自动计算 ES、EF、LS、LF、TF
  - 智能识别关键路径和关键任务
  - 拓扑排序和循环依赖检测

- **任务管理系统**
  - 完善的任务 CRUD 操作
  - 支持任务状态、优先级、完成度管理
  - 可视化依赖关系管理
  - 命令模式支持撤销/重做

- **数据统计仪表板**
  - 实时计算项目工期、任务数、关键任务数、完成进度
  - 即将到期任务提醒（7天内）
  - 多维度数据可视化

- **数据导入导出**
  - JSON 格式完整导入导出
  - PNG 高清图片导出
  - CSV 任务列表导入导出
  - 数据自动迁移和版本兼容

- **项目模板系统**
  - 内置软件开发、产品发布、营销活动等模板
  - 快速创建项目

- **响应式设计**
  - 完美适配手机（< 600vp）、平板（600-840vp）、折叠屏（> 840vp）
  - 深色/浅色主题自动适配
  - 语义化颜色系统

#### 技术特性
- 分层架构设计（表现层、业务层、服务层、数据层）
- 服务容器和依赖注入
- 响应式数据绑定（@Observed/@ObjectLink）
- 事件总线（EventBus）
- 命令模式（CommandHistory）
- Canvas 渲染性能优化（60fps）
- 本地数据持久化（Preferences）

## 版本说明

### 版本号规则
- 主版本号：重大架构变更或不兼容的 API 修改
- 次版本号：向下兼容的功能性新增
- 修订号：向下兼容的问题修正

### 版本代码规则
格式：`主版本 * 1000000 + 次版本 * 1000 + 修订号`
- 1.0.0 → 1000000
- 1.1.0 → 1001000
- 1.0.1 → 1000001
