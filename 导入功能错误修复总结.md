## 错误列表及修复方案

### 1. ImportService.ets - 对象字面量作为类型声明错误

**错误信息**:
```
ERROR: 10605040 ArkTS Compiler Error
Error Message: Object literals cannot be used as type declarations (arkts-no-obj-literals-as-types)
At File: ImportService.ets:55:12, 60:18, 68:25, 78:26
```

**问题原因**:
在 ArkTS 中，不能在接口定义内部使用匿名对象字面量作为类型。必须为每个嵌套对象创建独立的接口。

**修复方案**:
将嵌套的对象字面量拆分为独立的接口：

```typescript
// 修复前 (错误)
interface ImportProjectData {
  project: {
    tasks: Array<{
      checklist?: Array<{
        id?: string;
        text: string;
      }>;
    }>;
  };
}

// 修复后 (正确)
interface ImportChecklistItem {
  id?: string;
  text: string;
  isCompleted?: boolean;
}

interface ImportTaskData {
  id?: string;
  name: string;
  checklist?: ImportChecklistItem[];
  // ... 其他字段
}

interface ImportProject {
  id?: string;
  name: string;
  tasks: ImportTaskData[];
  // ... 其他字段
}

interface ImportProjectData {
  version?: string;
  exportTime?: string;
  project: ImportProject;
}
```

**新增接口**:
1. `ImportChecklistItem` - 检查清单项接口
2. `ImportTaskData` - 任务数据接口
3. `ImportDependency` - 依赖关系接口
4. `ImportProject` - 项目数据接口

### 2. ImportService.ets - 未类型化对象字面量错误

**错误信息**:
```
ERROR: 10605038 ArkTS Compiler Error
Error Message: Object literal must correspond to some explicitly declared class or interface
At File: ImportService.ets:375:73, 407:18
```

**问题原因**:
在 map 函数中返回对象字面量时，没有明确指定返回类型。

**修复方案**:

#### 2.1 ChecklistItem 转换

```typescript
// 修复前 (错误)
checklist: (taskData.checklist || []).map((item, itemIndex) => ({
  id: `checklist_${Date.now()}_${index}_${itemIndex}`,
  text: item.text || '',
  isCompleted: item.isCompleted ?? false
}))

// 修复后 (正确)
const checklistItems: ChecklistItem[] = (taskData.checklist || []).map((item, itemIndex): ChecklistItem => {
  return {
    id: `checklist_${Date.now()}_${index}_${itemIndex}`,
    text: item.text || '',
    isCompleted: item.isCompleted ?? false
  };
});
```

#### 2.2 Dependency 转换

```typescript
// 修复前 (错误)
project.dependencies = (projectData.dependencies || [])
  .map(dep => {
    if (fromExists && toExists) {
      return { fromId, toId };
    }
    return null;
  })
  .filter(dep => dep !== null) as Dependency[];

// 修复后 (正确)
project.dependencies = (projectData.dependencies || [])
  .map((dep): Dependency | null => {
    const fromId = oldIdToNewId.get(dep.fromId) || dep.fromId;
    const toId = oldIdToNewId.get(dep.toId) || dep.toId;
    
    if (fromExists && toExists) {
      const dependency: Dependency = { fromId, toId };
      return dependency;
    }
    return null;
  })
  .filter((dep): dep is Dependency => dep !== null);
```

**关键改进**:
- 明确指定 map 函数的返回类型
- 使用类型谓词 `dep is Dependency` 进行类型守卫
- 避免使用 `as` 类型断言

### 3. Home.ets - result.project 可能为 undefined

**错误信息**:
```
ERROR: 10605999 ArkTS Compiler Error
Error Message: 'result.project' is possibly 'undefined'
At File: Home.ets:1328:34
```

**问题原因**:
在 setTimeout 回调中访问 `result.project`，但 TypeScript 无法保证在异步回调执行时该属性仍然存在。

**修复方案**:

```typescript
// 修复前 (错误)
setTimeout(() => {
  this.getUIContext().getRouter().pushUrl({
    url: 'pages/Index',
    params: { projectId: result.project.id },  // 这里可能为 undefined
    // ...
  });
}, 500);

// 修复后 (正确)
setTimeout(() => {
  if (result.project) {
    this.getUIContext().getRouter().pushUrl({
      url: 'pages/Index',
      params: { projectId: result.project.id },
      // ...
    });
  }
}, 500);
```

**关键改进**:
- 添加 null 检查保护
- 确保类型安全

### 4. Home.ets - StorageService 类型不匹配

**错误信息**:
```
ERROR: 10605030 ArkTS Compiler Error
Error Message: Structural typing is not supported (arkts-no-structural-typing)
At File: Home.ets:312:52

ERROR: 10505001 ArkTS Compiler Error
Error Message: Argument of type 'StorageService' is not assignable to parameter of type 'FileStorageService'
At File: Home.ets:312:52
```

**问题原因**:
ImportService 原本要求 `FileStorageService` 类型，但实际传入的是 `StorageService` 类型。这两个类型虽然接口相似，但在 ArkTS 中不支持结构化类型（structural typing），必须精确匹配类型。

**修复方案**:

```typescript
// 1. 修改 ImportService 的导入语句
// 修复前
import { FileStorageService } from './FileStorageService';

// 修复后
import { StorageService } from './StorageService';

// 2. 修改 ImportService 类的属性和构造函数
// 修复前
export class ImportService {
  private fileStorageService: FileStorageService;
  
  private constructor(fileStorageService: FileStorageService) {
    this.fileStorageService = fileStorageService;
  }
  
  public static getInstance(fileStorageService: FileStorageService): ImportService {
    // ...
  }
}

// 修复后
export class ImportService {
  private storageService: StorageService;
  
  private constructor(storageService: StorageService) {
    this.storageService = storageService;
  }
  
  public static getInstance(storageService: StorageService): ImportService {
    // ...
  }
}

// 3. 更新所有使用 fileStorageService 的地方
// 修复前
await this.fileStorageService.saveProject(project);

// 修复后
await this.storageService.saveProject(project);
```

**关键改进**:
- 使用正确的类型（StorageService）
- 更新所有相关引用
- 确保类型一致性

### 5. ImportService.ets - 不支持 is 类型谓词错误

**错误信息**:
```
ERROR: 10605096 ArkTS Compiler Error
Error Message: Type guarding is supported with "instanceof" and "as" (arkts-no-is)
At File: ImportService.ets:436:22
```

**问题原因**:
ArkTS 不支持 TypeScript 的 `is` 类型谓词（type predicate）。只支持 `instanceof` 和 `as` 进行类型守卫。

**修复方案**:

```typescript
// 修复前 (错误)
project.dependencies = (projectData.dependencies || [])
  .map((dep): Dependency | null => {
    // ... 处理逻辑
    if (fromExists && toExists) {
      const dependency: Dependency = { fromId, toId };
      return dependency;
    }
    return null;
  })
  .filter((dep): dep is Dependency => dep !== null);  // 这里使用了 is 类型谓词

// 修复后 (正确)
const validDependencies: Dependency[] = [];
(projectData.dependencies || []).forEach((dep) => {
  const fromId = oldIdToNewId.get(dep.fromId) || dep.fromId;
  const toId = oldIdToNewId.get(dep.toId) || dep.toId;
  
  // 只保留有效的依赖关系
  const fromExists = project.tasks.some(t => t.id === fromId);
  const toExists = project.tasks.some(t => t.id === toId);
  
  if (fromExists && toExists) {
    const dependency: Dependency = { fromId, toId };
    validDependencies.push(dependency);
  }
});

project.dependencies = validDependencies;
```

**关键改进**:
- 使用 `forEach` 循环替代 `filter` 方法
- 直接构建类型化的数组，避免使用类型谓词
- 代码更清晰，易于理解
