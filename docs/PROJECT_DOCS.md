# EasyFlow (一思不漏) - 作品介绍文档

## 1. 作品简介

**名称**：EasyFlow (一思不漏)
**Slogan**：三思而后行，一思则不漏
**上架状态**：已上架华为应用市场 (HarmonyOS)

**EasyFlow** 是一款专为 **HarmonyOS** 打造的专业项目管理应用，它巧妙融合了**“备忘录的时间维度”**与**“思维导图的逻辑维度”**，旨在为用户提供一个既能把控宏观节奏，又能厘清微观逻辑的高维效率工具。

其核心理念源于“三思而后行，一思则不漏”：
*   **三思而后行 (逻辑维度)**：通过可视化的网络图和关键路径算法，让用户在行动前理清任务依赖，识别项目瓶颈。
*   **一思则不漏 (时间维度)**：通过日历集成和智能提醒，确保每一个细分任务都能在准确的时间点被执行，无一遗漏。

EasyFlow 不仅仅是一个工具，更是一种**以终为始**的项目思维方式。它填补了 HarmonyOS 生态中专业可视化项目管理工具的空白，帮助用户将复杂的项目层层拆解，化繁为简。

## 2. 核心亮点

### 维度一：逻辑的胜利 —— 可视化关键路径分析
EasyFlow 致力于解决“任务之间不仅有先后，更有逻辑”的问题：
*   **工业级 CPM 引擎**：内置专业的关键路径算法 (Critical Path Method)，毫秒级计算任务的**最早/最晚开始时间 (ES/LS)** 及 **总浮动时间 (TF)**。通过 **DFS 深度优先搜索** 实时检测循环依赖，自动识别决定项目总工期的“至关重要”路径，让项目风险无处遁形。
*   **自由画布与思维导图体验**：摒弃死板的表格，提供基于 **Canvas 2D** 高性能渲染的无限画布。用户可以像画思维导图一样自由拖拽节点，用贝塞尔曲线构建复杂的任务依赖网络，让逻辑梳理变得直观且自由。
*   **原子化节点工作台 (Node Workspace)**：(进阶功能) 突破传统项目管理软件的固化形态，引入**原子化组件组装**概念。用户可通过“所见即所得”的编辑器，从组件库中拖拽**进度条、标签、人员、清单**等原子组件，像搭积木一样定义专属的节点数据结构，满足不同领域（如软件研发、活动策划）的个性化需求。

### 维度二：时间的掌控 —— 深度日历集成
EasyFlow 确保逻辑规划能够落地为具体的时间行动：
*   **系统级日历同步**：拒绝应用孤岛，通过 Calendar Kit 将任务无缝注入 **HarmonyOS 系统日历**。利用系统的智能提醒服务，确保每个截止日期都能穿透锁屏，直达用户感知。
*   **缩略进度模式**：专为移动端优化的可视化语言，通过双层环形进度条直观展示任务的“时间流逝度”与“工作量完成度”的偏差，让进度滞后一目了然。

### 维度三：体验的极致 —— 原生流畅交互
*   **全场景响应式设计**：深度应用 **ArkUI** 的 `BreakpointSystem`，实现一套代码完美适配手机、折叠屏和平板。
*   **系统级拖拽交互**：集成 **Unified Data Channel (统一数据通道)** 与 Drag & Drop API，实现跨组件、跨应用的丝滑拖拽体验。
*   **流畅手势**：支持双指平移、缩放画布，长按拖拽节点。每一个交互都经过精心打磨，提供丝滑的 60fps 体验。

### 维度四：数据的自由 —— 多格式互通
*   **灵活导入导出**：支持 **JSON** (全量备份)、**CSV** (Excel 数据分析) 和 **PNG** (高清矢量级导出) 三种格式，满足数据迁移、汇报演示和二次分析的多样需求。
*   **安全本地存储**：数据完全存储于本地沙箱，保障用户隐私安全。

## 3. HarmonyOS 关键特性应用情况

EasyFlow 是完全基于 HarmonyOS SDK API 17 开发的原生应用，技术栈深度挖掘了系统潜能：

### (1) ArkUI 声明式开发框架
*   **高性能渲染**：利用 `@ObjectLink` 和 `@Observed` 实现细粒度状态观测，结合 **Canvas 离屏渲染** 技术，在绘制上千节点的复杂网络图时依然保持极高的帧率。
*   **交互创新**：通过 **DragController** 和 **UnifiedData** 实现组件库与画布之间的高精原生拖拽。

### (2) Core File Kit (文件基础服务)
*   **沙箱文件管理**：通过 `fileIo` 接口构建 `FileStorageService`，严格遵循 HarmonyOS 沙箱机制，实现用户数据的加密隔离存储与流式读写。

### (3) Calendar Kit (日历服务)
*   **场景化服务互通**：不自建冗余后台，而是通过标准协议读写系统日历数据库，将应用数据深度融入 HarmonyOS 智慧生活服务流。
