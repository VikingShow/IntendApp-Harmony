## 📚 文档体系说明

本项目提供了**三层递进式**的学习文档体系：

### 1. 基础层：原有学习指南
- **文件**：`LEARNING_GUIDE.md`（2244行）
- **定位**：入门友好，循序渐进
- **内容**：基础知识、核心技术、实战练习
- **适合**：初学者、转行开发者
- **学习周期**：6-8个月

### 2. 进阶层：高级学习指南  
- **文件**：`ADVANCED_LEARNING_GUIDE.md`
- **定位**：深度解析，跨领域整合
- **内容**：
  - TypeScript/ArkTS 语言深度（泛型、装饰器、异步编程）
  - HarmonyOS 平台开发（生命周期、权限、文件系统）
  - ArkUI 框架精通（状态管理、布局系统、响应式设计）
  - Canvas 2D 高级渲染技术
- **适合**：有一定基础的开发者
- **学习周期**：3-4个月

### 3. 专家层：全面技术指南
- **文件**：`COMPREHENSIVE_TECHNICAL_GUIDE.md`
- **定位**：算法深度、架构设计、未来功能
- **内容**：
  - 图算法完整实现（CPM、最短路径、最大流）
  - 数据可视化理论与实践
  - 甘特图实现详解
  - 云同步与实时协作
  - AI 辅助开发
- **适合**：高级开发者、架构师
- **学习周期**：持续学习

## 🌟 现有项目技术栈全景

### 前端技术
```
ArkTS / TypeScript
├── 类型系统：接口、泛型、装饰器
├── 面向对象：类、继承、多态
├── 异步编程：Promise、async/await
└── 模块化：import/export

ArkUI 框架
├── 声明式 UI：@Component、build()
├── 状态管理：@State、@Observed、@ObjectLink
├── 生命周期：aboutToAppear、aboutToDisappear
└── 响应式布局：Flex、Grid、断点系统
```

### 图形渲染
```
Canvas 2D API
├── 基础绘制：矩形、圆形、路径、文本
├── 坐标变换：translate、scale、rotate
├── 手势识别：单指拖拽、双指缩放/平移
└── 性能优化：节流、缓存、离屏渲染
```

### 算法与数据结构
```
关键路径法（CPM）
├── 拓扑排序：Kahn 算法
├── 正向传递：计算 ES、EF
├── 反向传递：计算 LS、LF
└── 关键路径识别：TF = 0

图算法
├── 深度优先搜索（DFS）：循环检测
├── 广度优先搜索（BFS）：层级遍历
└── 碰撞检测：点与矩形/圆形
```

### 架构设计
```
设计模式
├── 单例模式：AppState、ProjectManager
├── 命令模式：CommandHistory（撤销/重做）
├── 观察者模式：EventBus（事件总线）
└── 服务容器：ServiceContainer（依赖注入）

分层架构
├── 表现层：Pages、Components
├── 业务层：ProjectManager、Services
├── 数据层：ProjectData、Storage
└── 工具层：Utils、Helpers
```

### 数据管理
```
持久化
├── Preferences：轻量级 KV 存储
├── 文件系统：JSON/CSV/PNG 文件操作
└── 数据迁移：版本兼容与自动升级

导入导出
├── JSON 格式：完整项目数据
├── CSV 格式：任务列表
└── PNG 格式：项目可视化图片
```

## 🚀 未来功能与所需技术

### 功能 1：甘特图视图

**需要学习的内容：**

```
   → COMPREHENSIVE_TECHNICAL_GUIDE.md § 2.2.2 甘特图实现

```

**实现步骤：**
1. 设计甘特图数据结构
2. 实现时间轴渲染器
3. 添加任务条绘制
4. 实现拖拽交互
5. 整合到现有项目

**预计工作量**：2-3周

### 功能 2：资源管理系统

**需要学习的内容：**
```
1. 资源分配算法
   → 最大流算法
   → 资源平衡算法

2. 数据模型扩展
   → 资源实体设计
   → 分配关系管理

3. UI 组件
   → 资源视图
   → 分配编辑器
```

**关键技术点：**
- 资源冲突检测
- 负载均衡算法
- 资源利用率统计

**预计工作量**：3-4周

### 功能 3：云同步与协作

**需要学习的内容：**
```
1. WebSocket 实时通信
   → COMPREHENSIVE_TECHNICAL_GUIDE.md § 3.1.1 WebSocket 实时通信

2. 冲突解决机制
   → 操作转换（Operational Transformation）
   → CRDT（Conflict-free Replicated Data Types）

3. 服务端开发
   → Node.js / Express
   → 数据库设计（MongoDB / PostgreSQL）
   → RESTful API 设计
```

**架构设计：**
```
客户端（HarmonyOS App）
    ↕ WebSocket
云服务（Node.js Server）
    ↕ Database
数据存储（MongoDB）
```

**预计工作量**：6-8周

### 功能 4：AI 智能助手

**需要学习的内容：**

```
1. AI 模型集成
```

**功能示例：**

```
1. 挣值管理（EVM）

2. 蒙特卡洛模拟
   → 概率分布
   → 随机模拟
   → 结果统计
```
